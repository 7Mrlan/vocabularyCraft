# 第二轮：卡、词书、反馈与调度

> 对第一轮方案的修正与深化。核心修正：**阴阳是概念，不是配色。**
> 卡片两面跟随同一套明暗主题；区分它们的是内容与材质隐喻，不是一黑一白。

---

## 1. 修正：卡的两面不等于黑白

第一轮把「阳面=纸、阴面=夜」写成了字面配色，这是错的：

- 暗色模式下会出现一张刺眼的白面，亮色模式下会出现一张突兀的黑面；
- 而且它把「两个系统」偷换成了「两种皮肤」，概念被颜色吃掉了。

**改法：一张卡，两面，跟随当前主题。** 亮色时两面都是纸，暗色时两面都是墨；
区分靠三件事：

1. **角色**：正面是「读」——查词入口；背面是「答」——今天要背什么。
2. **排版**：正面像词典的索引卡（词、音标、一行释义、细双线）；背面像抽认卡
   （数字、进度、书名、印章）。
3. **内容密度**：正面安静、留白多；背面信息略多但仍在同一张卡上。

同一个翻转手势，在两个地方复用：

- 首页：小卡翻面 = 切换系统（慢，420ms）；
- 学习会话：同一张卡翻面 = 看释义（快，220ms）。

用户只需要学一次手势，两个地方都成立。这是「双系统」真正的黏合剂。

## 2. 卡的形态：从「首页一块牌」到「一张会变成系统的牌」

### 2.1 尺寸与比例（小巧、精致、高级）

| 项 | 值 |
|---|---|
| 宽 | `min(272.dp, screenWidth × 0.68)` |
| 比例 | 宽:高 = 1 : 1.42（接近索引卡，不像手机海报） |
| 圆角 | 16dp |
| 边框 | 内缩 1px 高光，白色 10%（暗色 8%） |
| 阴影 | 18dp，藏青 12%（暗色黑 45%） |
| 纸纹 | 2% 噪点，只加在卡面，不加在文字上 |
| 主字 | 衬线 30sp（词）/ 数字衬线 34sp（背面） |
| 索引行 | 衬线斜体 11sp，墨色 55% |
| 装饰 | 一条 1px 细线 + 学习面右侧一枚 3mm 珊瑚印章；**没有第二种装饰** |

卡不铺满屏幕，四周留出至少 64dp 的空白；它必须看起来像**可以拿在手里的东西**，
而不是一个页面容器。

### 2.2 翻面即「变成系统」

首页不是「一张卡 + 一堆快捷入口」，而是：卡居中，卡外只有一行极小的状态
（今日到期数 / 当前词书），点卡才进入。

一次切换分两拍，总时长 520ms：

```
0ms ─────────── 90° ─────────── 180° ─────────── 520ms
  卡绕 Y 轴转起     卡背对屏幕      背面内容淡入       系统页面（从卡的范围展开）
  scale 1→0.96    内容在此换面      卡本身开始放大     完成，卡隐去
```

- 第一拍（0–240ms）：卡翻到 90°，缩到 0.96，阴影降到最低；
- 第二拍（240–520ms）：目标系统从卡的矩形范围**展开**到全屏（scale + 圆角从 16dp
  收到 0），同时卡淡出；
- 返回时反向播放，系统收回成卡；从学习页返回，卡停在背面。

实现上不引入共享元素框架：记录卡的屏幕 bounds，目标页用 `graphicsLayer` 的
`scale/translation` 从该 bounds 反推初始值即可。目标页首帧必须是完整内容，
所以进入前要把会话队列准备好（本地，无网络）。

### 2.3 出现方式：发牌

App 冷启动时，首页不是直接出现，而是一副牌从底部**发出一张**：卡从下方 40dp
滑入，带 2° 的轻微旋转回正，220ms 落定，只此一次；热启动不再重复。
这是全 App 唯一的「入场动画」，其余仍然零转场。

### 2.4 动效红线

- 旋转节点内只允许文字、纯色、细线；禁止模糊、Haze、地图、图片；
- 两面都提前组合，靠 `visible` 控制，避免翻到一半才首次合成；
- 90° 换面时内容必须无动画切换，否则会看到「两层同时在转」；
- 系统开启「移除动画」时：不转、不放大，直接淡切 120ms。

## 3. 词书：一切的地基

词书不是「一堆词」，而是三个决定：**收哪些词、按什么顺序、怎么算学会**。

### 3.1 选词的依据（科学部分）

- 阅读理解需要约 **98% 的词汇覆盖率**才能不查词顺畅读（Nation 的经典结论）；
  口语的覆盖率门槛更低，约 95–98%。
- 约 **3000 个词族（word family）** 能覆盖日常口语的绝大部分；阅读要 8000–9000。
- 因此词书应该按**词族**组织，而不是按屈折形式：`great / greater / greatly /
  greatness` 在学习上是一个单位。我们已经有 vocabulary.com 的 `wordFamily`，
  可以直接归并。
- 排序：**词频降序**是初学者的最优解（先学最常用的，尽快获得覆盖率）；
  进阶阶段可提供「按字母」作为查找型顺序，但默认仍是词频。

### 3.2 建议的词书阶梯（核心优先）

| 词书 | 规模 | 覆盖目标 | 来源 |
|---|---|---|---|
| 核心 1000 | 1000 词族 | 口语约 85% | 词频前 1000（COCA/SUBTLEX 交集） |
| **核心 3000** | 3000 词族 | 口语 95%+，阅读约 90% | 词频 + NGSL 校验 |
| 核心 5000 | 5000 词族 | 阅读过渡 | 词频 |
| 学术核心 | 约 960 词族 | 论文/教材 | NAWL（New Academic Word List） |
| 四六级核心 | 约 2000 / 2500 | 考试 | 考试大纲词表 |
| 考研核心 | 约 3000 | 考试 | 考试大纲词表 |
| 雅思 / 托福核心 | 各约 3000 | 考试 | 公开词表整理 |
| 查过的词（自动） | 动态 | — | 本地缓存 |
| 自建（粘贴文本） | 动态 | — | 用户输入 |

推荐先做 **核心 3000**（学习价值最高、不依赖考试大纲的版权边界）与
**学术核心**（NAWL 是公开授权词表），再补考试类。

### 3.3 词书牌堆

- 一次露三张，中间完整，左右各露 24dp 边；
- 牌面：书名（衬线）、词族数、进度环（细线，不用粗进度条）、一行标签；
- 滑动切换，松手吸附；选中牌上浮 8dp、阴影加深，其它牌降到 60% 明度；
- 点「开始这本」→ 成为当前词书；再点一次进入学习。

### 3.4 词书与记忆解耦

FSRS 状态挂在**词**上。换书只改「接下来学什么」，不清空任何记忆；
提供「暂停这本书」，不提供「移出记忆」（那是墨墨为了卖扩容的机制）。

## 4. 学习会话

### 4.1 一张卡的两面

```
正面（读）                        背面（答）
┌──────────────────┐            ┌──────────────────┐
│  fusion     🔊   │            │  fusion     🔊   │
│  /ˈfjuːʒən/      │   翻面      │  n. 融合，结合…   │
│                  │  ───────▶  │  “Fusion is the   │
│  轻点查看释义      │  ◀───────  │   process of…”   │
│                  │   220ms    │  词族 · 同义       │
└──────────────────┘            │ 忘记 模糊 认识 秒懂 │
                                └──────────────────┘
```

- 翻面动效与首页同一套，但更快、更浅（旋转 180°，scale 不缩）；
- 释义、例句、词族全部复用查词页的排版组件，保证两个系统是同一个产品；
- 四档反馈映射 FSRS：忘记=Again、模糊=Hard、认识=Good、秒懂=Easy；
- 「秒懂」用最轻的文字按钮，避免误点；它解决的是「认识但太慢」的记忆，
  不该被当成默认。

### 4.2 当日规则（抄墨墨，写清楚）

- 一个词当天第一次出现时，反馈决定长期排期；
- 当天第二次及以后出现，反馈只决定「今天还回不回来」，不改长期状态；
- 会话内用内存集合 `seenToday` 判断，不写库。

### 4.3 拼写模式（必须有）

- 触发：每组 10 个新词结束后，或一轮复习的末尾，抽出本组里「认识 / 秒懂」的词；
- 题面：中文释义 + 首字母 + 字母格（`f _ _ _ _ _`）+ 发音按钮；
- 输入：系统键盘，逐字校验；错一个字母，字母格轻抖一次（80ms），不弹红；
- 提交正确：卡片右上角盖一枚珊瑚印章（120ms 缩放落定），进入下一题；
- 拼错：标记为 `Hard` 重新入队，本轮结束前必须再拼一次；
- 科学依据：**提取练习（retrieval practice）与产出（production）**比再认更能
  巩固记忆；拼写是最难的提取路径，所以只对已「认识」的词做，避免挫败。
- 不做「听写」，因为 TTS 音色不足以支撑听辨训练。

### 4.4 反馈：让每一拍都有回应（上瘾但不低俗）

不背单词的口碑来自「每一次操作都有即时、确定的回应」。我们按工程指标做：

| 通道 | 规格 |
|---|---|
| 视觉按下 | ≤ 50ms 出现按压态（缩放 0.98 / 明度 -4%） |
| 状态变化 | ≤ 120ms 完成评级色/文案变化 |
| 卡片位移 | 180–260ms，`FastOutSlowIn`，不弹跳 |
| 触感 | 认识=轻 tick；秒懂=双 tick；模糊=短震；忘记=一次闷响（`HapticFeedbackConstants`） |
| 声音（可选，默认开） | 正确=极轻的纸张声；错误=一声木质轻叩；音量 20%，可关 |
| 进度 | 顶部 1px 细线，按剩余数连续收缩，不跳格 |
| 下一次见面 | 评级后显示「下次见：12 天后」——用 FSRS 的可提取性算，真实且有信息量 |
| 里程碑 | 每 10 张，细线末端出现一个 2mm 圆点；完成一天，卡背盖一枚印章 |

明确不做：彩带、金币、红点、连续天数的道德绑架、假的稀缺奖励。
上瘾的来源应该是「记忆真的在变牢」，而不是赌场机制。

## 5. FSRS-5 与艾宾浩斯：给选择，但说清代价

### 5.1 两者的差别

- **艾宾浩斯（经典模式）**：固定间隔阶梯（如 1、2、4、7、15、30、60 天）。
  可预测、心里有数；但忽略词的难度与个人差异，简单词被过度复习，难词复习不足。
- **FSRS-5（智能模式）**：每张卡维护稳定度与难度，按目标保留率排期。
  同等的记忆效果下复习次数更少；代价是需要积累几十到几百次复习才能充分个性化，
  且「下次什么时候见」不那么好预测——所以我们在界面上把它显示出来。

### 5.2 产品设计

- 首次进入背词系统时给一次选择，用两句话说明差异，默认 **FSRS-5**；
- 设置里可随时切换，切换时做**无损迁移**：
  - FSRS → 艾宾浩斯：取当前间隔，落到最近的阶梯；
  - 艾宾浩斯 → FSRS：用当前间隔初始化稳定度，难度取中位数；
- 调度器是设置级（全局），不是每卡级，避免同一个队列里两种节奏；
- 词书之间共用同一份记忆状态。

### 5.3 默认参数

先用 FSRS-5 的公开默认参数，不内置优化器；等本地积累到 400 条以上复习记录，
再考虑在设置里提供「用我的数据优化参数」（离线计算，一次性）。

## 6. 数据与结构（在 P0 基础上）

```kotlin
enum class Scheduler { FSRS5, EBBINGHAUS }

// 新增设置
scheduler: Scheduler = FSRS5
dailyNew: Int = 10
dailyReviewCap: Int? = null      // null = 不限
currentBookId: Long?

// 词书
books(id, name, kind, totalFamilies, createdAt)
book_words(bookId, lemma, ord)   // 存词族代表词，展示时展开家族

// 学习日志（统计与参数优化用）
study_log(id, lemma, rating, mode, at)
```

会话队列纯内存：`due + new`，一次最多预取 20 张的 `WordEntry`，避免翻页时等网络。

## 7. 需要下一轮讨论的点

1. **词书范围**：先做核心 3000 + 学术核心（公开词表、无版权争议），还是直接上
   四六级/考研（更贴你的目标，但词表需要整理与校对）？
2. **词族怎么展示**：卡片只显示代表词，背面用「同族」一行列出变形，点开可看全族？
3. **每日节奏**：新词 10 个是否合适？复习上限要不要默认 100 防堆积？
4. **拼写比例**：每组 10 个里抽几个？还是只抽「秒懂」的？
5. **声音**：默认开还是默认关？纸张声/木叩声需要找可商用音源或自己合成。
6. **首页卡的信息密度**：背面除了「待复习 / 连续天数 / 当前词书」，还要不要放
   「今日预计用时」？
