# 背单词系统调研与「阴阳卡」双系统方案

> 存档说明（2026-11-11）：本文是 2026-11 的调研与设计记录，写在 `test` 分支上，
> 部分方案（阴阳双面卡、艾宾浩斯切换、`study_log` 等）没有落地。
> 当前实现以 README 与 `docs/DESIGN.md` 为准。

---

## 1. 起点

Wordloom 现在已经把「英译英查词」做完整了：搜索联想、词条页（音标 / 发音 / 词形 /
导读 / 释义 / 例句 / 同义词 / 词族）、词表、FSRS-5 复习、四选一练习、地图回看、
长按翻译、备份恢复。

下一步不是再堆查词功能，而是把**背单词**做成第二个系统，并且和查词长在同一张卡上。
参考对象：不背单词（主）、墨墨背单词（次）。

我们已有的底层其实比想象中更接近：`cards` 表里跑的已经是 FSRS-5，和墨墨公开的
FSRS 系列同源；缺的是「学习卡」这一层皮、词书、每日计划、统计与提醒。

## 2. 两款 App 拆解

### 2.1 不背单词

官方口径与商店页信息（见文末来源）：

- **内容**
  - 150 万+ 原声例句，取自英美剧、纪录片、歌曲、新闻，自动发音；
  - 17 万+ 历年真题例句（中考到考研）；
  - 200+ 词书 / 教材词表；
  - 2000+ 词根词缀、5000+ 派生树、5 万+ 词组搭配、近反义词、词形变化；
  - 柯林斯英汉双解，考义高亮、考点标记。
- **学习流程**
  - 单词卡：单词、音标（可切英/美音）、中文释义、词根词缀；**右滑看例句**；
  - 学完一组后进入**拼写测试**；
  - 复习按艾宾浩斯曲线排期，以复习为主、新学为辅，强调碎片时间。
- **其他**：随身听（音频列表连播）、签到打卡、分享、酷币。

它的护城河是**原声例句**：把词放回真实语境，用户记的是「那句话」而不是释义条目。
这一层我们拿不到（版权 + 数据），只能换等价物（第 4.4 节）。

体验上值得学的不是功能列表，而是**克制**：卡片上永远只有一个主角（词），释义和例句
都藏在一次手势之后；没有仪表盘式首页。

### 2.2 墨墨背单词

- **算法**：自研 MM 系列，公开了 FSRS；按每次反馈的时间点与记忆保留率动态排期，
  牢固的推后、易忘的提前。
- **反馈机制（最值得抄的部分）**
  - 新学：认识 / 不确定 / 不认识；复习：认识 / 模糊 / 忘记；
  - **只有当天第一次出现的反馈才影响长期排期**，当天后续出现只影响「隔几个词再来一次」；
  - 认识 → 当天不再出现，间隔逐步拉长（最长约一年）；
  - 模糊 → 当天至少再来一次，且数天内再复习；
  - 忘记 → 更高频重现；
  - 官方明确没有「完全记住」这个状态。
- **每日学习量**：不设固定「每日新词数」，而是给一个总学习压力值；顺序是
  **先复习后新学**，复习按遗忘程度从高到低排。
- **词书**：大量权威词书，支持「只背此书」「移出记忆」「熟知词」「不想背」，
  还能从自定义文本里提取单词。
- **可视化**：个人遗忘曲线、打卡日历。

### 2.3 对照到我们

| 能力 | 不背单词 | 墨墨 | Wordloom 现状 |
|---|---|---|---|
| 间隔重复 | 艾宾浩斯 | MM / FSRS | **FSRS-5 已有** |
| 学习卡（词→释义→例句） | 有 | 有 | 无（只有查词页） |
| 反馈档位 | 认识/不认识 等 | 三档 + 当天规则 | 复习页四档评分 |
| 词书 | 200+ | 大量 | 只有自建词表 |
| 每日计划 | 新词 + 复习 | 学习量，先复习后新学 | 只有到期队列 |
| 例句语境 | 原声（护城河） | 例句 + 助记 | vocabulary.com 例句 |
| 拼写 | 有 | 无 | 无 |
| 打卡 / 统计 | 有 | 有 | 无 |
| 提醒 | 有 | 有 | 无 |

结论：**算法不用重做，做「学习卡 + 词书 + 每日计划 + 统计」四件事**，外加提醒。

## 3. 产品主张：一张卡，两个世界

### 3.1 概念

首页不再是一列功能入口，而是**一张立着的卡**：

```
        ┌───────────────────────┐
        │                       │
        │   yang（纸面 / 查词）  │
        │                       │
        │   今天查过的词          │
        │   搜索框                │
        │                       │
        └───────────────────────┘
                  ⇅ 翻转
        ┌───────────────────────┐
        │   yin（夜色 / 背词）   │
        │                       │
        │   今日 12 待复习        │
        │   连续 7 天             │
        │   《考研核心》 34%      │
        └───────────────────────┘
```

- **阳面 = 查词**：纸色、墨色字，延续词条页的语言；放搜索、最近查过、每日一词。
- **阴面 = 背词**：深墨底、月白色字；放今日计划、连续天数、当前词书与「开始」。
- 两面的数据都是真的：阳面读最近词与每日一词，阴面读到期的 FSRS 卡与词书进度。
- 翻转是**唯一的高光动效**：整个 App 只有这一处允许 3D。

### 3.2 为什么是「卡」而不是「底部 Tab」

底部 Tab 会把两个系统并列成两个功能；卡把它们变成**同一个东西的两面**，切换本身
就是一次「选择」——这正是用户说的仪式感。也避免首页再多一条常驻栏。

### 3.3 翻转规格（动效设计）

一次翻转 = 一个 3D 旋转，不做任何多余位移：

| 项 | 值 |
|---|---|
| 轴 | `rotationY` 0 → 180 |
| 透视 | `cameraDistance = 12 × density`（避免近大远小过强） |
| 缩放 | 1 → 0.94（90°）→ 1，乘法叠加，让卡在转的中途「退后一步」 |
| 阴影 | 90° 时最低，两侧各一次轻微位移（光源固定左上） |
| 内容交换 | 在 90° 那一刻换面，背面预旋转 180° 做镜像补偿 |
| 时长 | 420ms，`FastOutSlowIn`，不允许弹跳 |
| 触感 | 过 90° 时 `HapticFeedbackConstants.CLOCK_TICK`，只一下 |
| 中断 | 手势中途松手：朝最近的一面收尾，不反向弹回 |
| 降低动效 | 系统开启「移除动画」时直接切面，不转 |

实现要点（Compose）：

- 用 `Animatable(0f → 180f)` 驱动 `graphicsLayer { rotationY = angle; cameraDistance = ... }`，
  两个面叠在同一个 `Box` 里，各占一半状态；
- 背面容器 `graphicsLayer { rotationY = 180f }` 预翻转，否则字是反的；
- 在 `angle >= 90f` 时切换 `visibleWorld`，切换本身没有动画，靠旋转掩盖；
- 两面都只画**轻内容**（文字与少量图形），禁止在旋转节点里放 Haze / 模糊 / 地图，
  否则每帧都在重算 backdrop；
- 翻转期间禁用点击，结束后按 `visibleWorld` 路由。

### 3.4 进入与返回

- 点卡面任意处 → 翻转；
- 翻到阴面后，点「开始」进入学习会话（普通页面跳转，**不加转场**，保持现有的即时切换原则）；
- 从学习页返回 → 回到阴面首页，卡保持阴面；
- 阳面点击搜索 → 走现有查词链路，完全不经过卡。

## 4. 背词系统

### 4.1 今日计划

抄墨墨的顺序，用我们自己的参数：

1. **先复习**：到期卡按「遗忘风险」从高到低（FSRS 的 `retrievability` 升序）；
2. **再新学**：每天新词数默认 10，可调 5/10/20/30；
3. 复习清空后如果新词额度还有，继续新词；两者都空 → 显示「今天清空了」的安静状态。

不设「学习量」抽象值——那是墨墨为了卖扩容做的包装；我们自用，直接给两个数字：
`每日新词`、`每日复习上限`（默认不限）。

### 4.2 学习卡

一面一卡，纵向：

```
┌────────────────────────────┐
│  fusion            🔊  🇺🇸  │   ← 词 + 发音
│  /ˈfjuːʒən/                │
│                            │
│        （留白）             │   ← 先不给释义
│                            │
│      轻点查看释义            │
└────────────────────────────┘
        ↓ 轻点 / 上滑
┌────────────────────────────┐
│  fusion            🔊       │
│  n.  融合，结合；核聚变…      │   ← 复用查词页的词性分栏
│                            │
│  “Fusion is the process of  │   ← 例句，可播放 TTS
│   combining two or more…”   │
│                            │
│  词族  fusion cooking …      │
│                            │
│  忘记   模糊   认识   秒懂    │   ← 四档
└────────────────────────────┘
```

- **内容复用**：释义、例句、词族、同义词直接读 `WordEntry`，与查词页共用同一套
  排版组件（词性列 + 释义列），两个系统看起来是同一个产品；
- **四档映射 FSRS**：`忘记 = Again`、`模糊 = Hard`、`认识 = Good`、`秒懂 = Easy`；
  墨墨只给三档，FSRS-5 需要四档才能区分「轻松想起」，多出来的一档放在最右，视觉上
  更轻（文字按钮而不是主按钮）；
- **当天规则**（抄墨墨）：一个词当天第二次出现时，反馈不再改长期排期，只决定它今天
  还回不回来。我们在会话内存一个 `seenToday` 集合即可，不写库。

### 4.3 反馈后的物理感

- 忘记：卡片轻微下沉 + 左右抖一下（1 次，120ms），立刻排回队列尾部；
- 模糊：卡片原地淡出，随后 3–5 张后再出现；
- 认识 / 秒懂：卡片向右上滑出，下一张从下方补位（220ms，`FastOutSlowIn`）；
- 全程不做整页转场；进度条只在顶部细线，不弹统计。

### 4.4 例句：拿不到原声，就给「可听的例句」

不背单词的原声我们复制不了，替代方案按优先级：

1. **vocabulary.com 例句**（已有）+ **系统 TTS**（`TextToSpeech`，离线）朗读句子；
2. 词条页的真人发音（已有）放在卡上，英美音可切；
3. 后续可选：接入某家 TTS 的更自然音色（只影响这一个组件）。

不做「随身听」——那是长音频产品，和碎片化学习冲突，自用也不需要。

### 4.5 拼写（P2）

- 认识 / 秒懂之后，按概率抽 20% 进入拼写：给中文释义 + 首字母，输入完整单词；
- 拼错视为 `Hard`，拼对维持原评级；
- 这一功能不单独做页面，就在学习卡背面换一个输入态。

## 5. 词书

### 5.1 卡片式选择

横向牌堆，一次露 3 张，中间一张完整：

```
      ╭─────────╮
   ╭──┤ 考研核心 ├──╮
   │  │ 3200 词  │  │
   │  │ ▓▓▓░░ 34%│  │
   │  ╰─────────╯  │
   ╰── 雅思核心 ────╯
```

- 牌面：书名（衬线）、词数、进度环或进度条、一行标签（考试 / 场景 / 自建）；
- 左右滑动切换，松手吸附；选中牌上浮 8dp 并投影加深；
- 点「开始这本」→ 该词书成为阴面的当前词书；再点一次进入学习；
- 已有词书列表（我们现在的「词表」）也以牌的形式进入这里——词表就是自建词书。

### 5.2 词书从哪来

三条来源，按落地顺序：

1. **生词本（自动）**：所有查过的词自动成一本「查过的词」，零成本，先让系统跑起来；
2. **内置精选包**：考研核心、四六级核心、雅思核心、学术高频，每本 1000–3000 词，
   从 vocabulary.com 的公开词表整理成 assets 里的纯文本（一词一行）；
3. **自定义**：粘贴一段文本 → 提取其中的英文词 → 去重、按出现顺序成书（墨墨的功能）。

词书只存「词序」，词的释义仍然走现有缓存/查询，不重复存储。

### 5.3 换书不丢记忆

FSRS 状态挂在**词**上（`cards.word`），不挂在书上。换词书只换「接下来学哪些词」，
已建立的记忆保留；这与墨墨的「移出记忆」是相反的选择——我们不做「移出记忆」，
只做「暂停某本书」。

## 6. 数据模型

```sql
-- 词书
CREATE TABLE books (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  kind TEXT NOT NULL,          -- builtin / custom / recent
  total INTEGER NOT NULL,
  createdAt INTEGER NOT NULL
);

CREATE TABLE book_words (
  bookId INTEGER NOT NULL,
  word TEXT NOT NULL,
  ord INTEGER NOT NULL,
  PRIMARY KEY (bookId, word)
);

-- 学习日志（统计用，不影响 FSRS）
CREATE TABLE study_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  word TEXT NOT NULL,
  rating INTEGER NOT NULL,     -- 1..4
  at INTEGER NOT NULL,
  mode TEXT NOT NULL           -- review / new / spelling
);

-- 设置（DataStore 或 SharedPreferences 均可）
-- dailyNew: Int = 10
-- currentBookId: Long?
```

`cards` 表不动：已有的 FSRS 字段就是学习状态。新增词进入学习时先查缓存/联网取
`WordEntry`，再 `addToDeck`，复用现有逻辑。

## 7. 导航结构

```
Home（一张卡，两个面）
├── Lookup 面
│   ├── Search → Word → Synonyms
│   ├── Lists
│   └── Map
└── Study 面
    ├── Books（牌堆）
    ├── Session（学习卡）
    ├── Stats（P2）
    └── Quiz（已有的四选一，作为「换一种方式复习」的入口）
```

- `World` 状态放在 `MainActivity` 或一个轻量 `AppState` 里，随进程存活；
- 学习会话是独立路由 `study/session`，返回直接 pop，无转场；
- 查词链路一行代码不改，卡只是它的新入口。

## 8. 性能与风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 翻转掉帧 | 3D 旋转 + 两面内容同时绘制 | 两面只放文字/简单图形；旋转期间关闭阴影与模糊；`graphicsLayer` 合成 |
| 首帧空白 | 背面第一次显示才组合 | 两面都提前组合，`alpha/rotation` 控制可见性 |
| 包体 | 现在 121MB，加词书会更大 | 词书只存词表文本（千词约 10KB）；先做 ABI split |
| 词书数据 | 内置包需要整理 | 先做「生词本」自动成书，验证闭环后再补包 |
| 例句版权 | 原声拿不到 | 只用 vocabulary.com 例句 + TTS，不搬运第三方音视频 |
| FSRS 三/四档 | 墨墨三档，我们四档 | 四档映射 Again/Hard/Good/Easy；「秒懂」权重最低，避免误点 |
| 学习量失控 | 到期堆积 | 复习上限默认不限但显示预计时长；新词数硬上限 |

## 9. 落地顺序

**P0（先跑通闭环）**
1. `test` 分支：`World` 状态 + 首页双面卡 + 翻转动效；
2. Study 面：今日计划（先复习后新学）+ 学习卡（正面词/背面释义与例句）+ 四档反馈；
3. 数据全部复用现有 `cards` 与缓存，不加表。

**P1（词书）**
4. `books` / `book_words` 表 + 生词本自动成书；
5. 牌堆式词书选择；内置 1–2 本精选包。

**P2（习惯）**
6. 统计页（连续天数、近 7 天、掌握度分布）；
7. 本地提醒（WorkManager，一天一条，可关）；
8. 拼写测试。

**P3（体验）**
9. 例句 TTS、英美音切换上卡；
10. APK 瘦身（ABI split + 资源裁剪）。
