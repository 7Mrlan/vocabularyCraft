# 首次下载动态引导（Onboarding）

> 状态（2026-11-12）：**已实现、已提交、未真机验证**。4.1 已接入首页「收纳 → 声音」配置页；
> 首次启动进入 4 屏引导，完成/跳过后写 `onboarding_v1_done`，首页抽屉可重新查看。

> 目标：第一次打开 App 时，用 4 屏以内讲清「这是什么」「AI 朗读怎么配」「学习卡怎么用」，
> 然后直接进入书架。可跳过，不阻塞离线使用；不重复打扰。

## 1. 设计原则

- **一屏一个概念**，标题大、正文短；每屏只有一个主按钮，一个「跳过」文字按钮。
- **动态但不炫技**：每屏只做一个动作（波浪推进、卡片翻转、书封面打开），不循环、不自动播放。
- **可跳过**：任何一屏都能跳过；跳过不等于完成配置，之后保留安静入口。
- **不阻塞**：没有网络、没有 key、没选书都能进入 App。
- **一次只出现一次**：完成或跳过后写 `onboarding_v1_done`；设置里提供「重新看引导」。
- 视觉沿用纸墨/藏蓝/珊瑚，衬线标题 + 无衬线正文；深色模式跟随主题。
- 触摸目标 ≥48dp；所有图标有 contentDescription；不做倒计时自动翻页。

## 2. 四屏流程

### 第 1 屏：欢迎（约 3 秒可读完）

```
┌─────────────────────────────┐
│        Wordloom             │  ← 衬线 34sp
│   查词 · 背词 · 都在这张卡上  │
│                             │
│   本地优先，不登录，不上传     │
│                             │
│        [ 开始 ]             │  ← 主按钮
│          跳过                │
└─────────────────────────────┘
```

- 背景：首页 hero 的藏蓝渐变 + 一条缓慢推进的波浪（一次性，300–500ms，不循环）。
- 主按钮「开始」→ 第 2 屏；「跳过」→ 直接进入 App 并写 flag。
- 不要求权限、不请求网络。

### 第 2 屏：让单词会说话（AI 朗读配置）

这是最重要的一屏，但只暴露最少字段：

```
┌─────────────────────────────┐
│  让单词和例句会说话           │
│                             │
│  使用你自己的 AI 语音服务      │
│  （MiMo / OpenAI 兼容）       │
│                             │
│  接口  [ 推荐 MiMo        ▾ ] │
│  模型  mimo-v2.5-tts-voicedesign │
│  音色  温润知性的成熟女声…     │
│  密钥  [••••••••••••]        │
│                             │
│  [ 测试发音 ]  [ 使用推荐配置 ]│
│          稍后配置             │
└─────────────────────────────┘
```

- 默认预填推荐配置：
  - endpoint `https://api.xiaomimimo.com/v1`
  - protocol `MIMO`
  - model `mimo-v2.5-tts-voicedesign`
  - voice 空
  - instructions 使用用户原来的中文描述
    （“温润知性的成熟女声，中低音，音色干净，吐字清晰，语速从容，句末自然下落，不过分甜。”）
- 用户只需要粘贴 **API key**；接口/模型/音色收在「高级」里，默认折叠。
- 「测试发音」合成一句固定英文 `Never make your students feel ignorant.`，显示
  `首字 x.xx s / 整句 x.xx s`；失败显示可读错误，不显示 key。
- 「使用推荐配置」保存配置并进入第 3 屏；「稍后配置」跳过并进入第 3 屏。
- 保存使用加密 `TtsConfigStore`（Android Keystore AES/GCM + AtomicFile）；key 不进 APK/备份/日志。
- 若用户已有 ebook 的配置，可提供「从 ebook 导入」入口（手动粘贴 endpoint/model/voice/key），
  不做自动读取其他 App 私有数据。

### 第 3 屏：一张卡，三种看法（学习卡怎么用）

用一张**可交互的小卡**演示，而不是纯文字：

```
┌─────────────────────────────┐
│  一张卡，三种看法             │
│                             │
│      ┌─────────────┐        │
│      │  make   🔊  │        │  ← 小卡
│      │  凭第一反应评分 │        │
│      └─────────────┘        │
│                             │
│  点四档评分 → 揭晓            │
│  左滑看例句 · 右滑回主卡       │
│  「中文」看释义 · 「记错了」重排 │
│                             │
│        [ 下一步 ]            │
└─────────────────────────────┘
```

- 小卡支持一次真实手势：左滑翻到例句，右滑回主卡；或用「试试左滑」按钮触发一次演示。
- 不要求评分、不写数据库；只是演示。
- 文案保持短：每行一句，最多三行。
- 主按钮「下一步」；「跳过」仍在。

### 第 4 屏：从书架开始

```
┌─────────────────────────────┐
│  从一本书开始                 │
│                             │
│  1  书架 → 选一本词书         │
│  2  开始学习 → 每天 10 个新词  │
│  3  左右滑看例句，书签收藏     │
│                             │
│  查词：搜索 / 长按选词翻译     │
│  复习：到期卡自动进队列        │
│                             │
│        [ 去书架 ]            │
└─────────────────────────────┘
```

- 「去书架」→ `books` 路由；同时写 `onboarding_v1_done = true`。
- 不自动打开某本书；用户自己选。
- 若第 2 屏没配置 TTS，本屏底部显示一条很轻的提示：
  「AI 朗读未配置 · 可在首页「收纳 → 声音」里设置」；不是弹窗。

## 3. 入口与持久化

- `OnboardingStore`（SharedPreferences，`wordloom_onboarding`）：
  - `onboarding_v1_done: Boolean`
  - `tts_setup_skipped: Boolean`
  - `onboarding_v1_seen_at: Long`
- `AppNav` 起始路由：
  - 未完成 → `onboarding`
  - 已完成 → `home`
- 首页收纳抽屉底部「重新看引导」清 flag 并跳 `onboarding`；不清 TTS 配置。
- 若 TTS 配置成功，`tts_setup_skipped = false`；首页不再显示未配置提示。
- 引导页不依赖 ViewModel 的业务数据；TTS 保存/试听通过 `SpeechService`，配置落在 `TtsConfigStore`。

## 4. UI 细节

- 全屏 `Box` + `HorizontalPager`（4 页，不可无限循环），底部 4 个点；只有当前页动。
- 每页进入时一个 220–320ms 的一次性动画：
  - 第 1 屏：波浪从左到右推进一次；
  - 第 2 屏：配置卡从下方 12dp 浮入；
  - 第 3 屏：小卡翻到 90° 时切换背面，再回正；
  - 第 4 屏：三个步骤逐条淡入（stagger 40ms）。
- 不做常驻无限动画；`rememberInfiniteTransition` 禁止出现在引导页。
- 主按钮：墨色胶囊（`wl.ink`），文字纸色；跳过：inkMuted 文字按钮。
- 深色模式：纸面/墨色跟随主题；第 1 屏 hero 固定藏蓝，文字白色。
- 键盘：第 2 屏 key 输入时 `imePadding`；错误提示在字段下方，不弹 Toast。
- 安全：key 输入框不用 `rememberSaveable`，避免密钥进入系统 saved state；旋转后重新输入即可。
- 无障碍：每页标题作为 `heading`；按钮有明确文案；小卡演示提供等价文字。

## 5. 实现文件（建议）

- `ui/onboarding/OnboardingScreen.kt`：Pager、四页、动画。
- `ui/onboarding/OnboardingStore.kt`：SharedPreferences flag。
- `ui/onboarding/TtsSetupPage.kt`：推荐配置 + key + 测试。
- `data/tts/TtsConfigStore.kt`：加密配置（见 `docs/AI-TTS.md`）。
- `MainActivity` / `AppNav`：起始路由判断；「重新看引导」入口。
- `ui/components/WlSheet.kt`：引导中的高级配置可复用抽屉风格，但引导页本身是全屏，不用抽屉。

## 6. 对抗性清单

| 场景 | 处理 |
|---|---|
| 用户跳过 | 写 done + skipped；首页保留轻量「AI 未配置」入口，不重复弹窗 |
| 没网络 | 引导可完成；测试发音失败显示错误；不阻塞进入 App |
| key 错误/额度不足 | 字段下可读错误；不显示 key；可稍后再配 |
| 用户没有 AI 服务 | 「稍后配置」；旧真人/Youdao 兜底仍可学习 |
| 旋转/进程恢复 | 当前页 + 输入内容用 `rememberSaveable`；不重复写 flag |
| 深色模式 | 跟随主题；第 1 屏固定藏蓝 |
| 小屏/大字体 | 每页可滚动；主按钮固定底部；不截断标题 |
| 无障碍 | 标题 heading、按钮文案、演示有等价文字 |
| 重复进入 | flag 完成后不再自动进入；设置里可重看 |
| 配置变更 | 换 model/voice 后缓存 key 变化；旧音频不复用 |
| 安全 | key 加密存储；不写日志/备份；release APK 无 key |

## 7. 验收

- 清数据后首次启动进入 4 屏引导；跳过/完成后不再自动出现。
- 第 2 屏可用推荐配置 + 用户 key 完成测试并保存；重启后仍生效。
- 第 3 屏小卡可左右滑一次；不写数据库。
- 第 4 屏「去书架」进入书架；首页无重复引导。
- release APK 不含 key；`grep`/BuildConfig 验证为空。
- 深色模式、字体放大、无网络三种情况各走一遍。
