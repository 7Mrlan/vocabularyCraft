## 字体

参考站用 **Open Sans**（正文）+ **Merriweather**（标题）+ **SSStandard**（图标字体）。

当前用平台字体族（`SansSerif` / `Serif`）起步，保证任何设备都能构建和渲染。
要 1:1 复刻：

1. 从 Google Fonts 下载 Open Sans / Merriweather 的 **可变字体或静态 TTF**（两者都是 OFL，可随 App 分发）
2. 放进 `app/src/main/res/font/`
3. 改 `ui/theme/Type.kt`：

```kotlin
val SansFamily = FontFamily(
    Font(R.font.open_sans_regular, FontWeight.Normal),
    Font(R.font.open_sans_semibold, FontWeight.SemiBold),
    Font(R.font.open_sans_bold, FontWeight.Bold),
)
val SerifFamily = FontFamily(
    Font(R.font.merriweather_regular, FontWeight.Normal),
    Font(R.font.merriweather_bold, FontWeight.Bold),
)
```

## 首页 hero（2026-11 改版）

圆形拼贴在手机宽度下有两种坏结果：要么被搜索框整块压住，要么为了露出来而撑出一大块空白，
把「随机一个词」推到离输入框很远的地方。所以 hero 改由**排版**承担识别度，不再放背景插画：

```
品牌行 ································ (词书 / 词表 / 地图 / 备份)
[ 搜索胶囊 56dp ]
↻ 随机一个词        ← 距输入框 14dp
～～～ 波浪 ～～～
```

- 唯一的高饱和元素是那条搜索胶囊，其余靠字重和层级拉开
- hero 高度由内容决定，没有单独占位的装饰层
- 波浪仍然是从深蓝到亮蓝的唯一边界语言

## 地图（已实现）

参考站的地图不是自然底图，而是**整片蓝色调**：陆地被压成浅蓝灰，水面是高饱和蓝，
标签本身也是蓝的，再叠一层上浅下深的渐变融进蓝色分区。我们复刻的是这套读法：

- **底图**：MapLibre Native + OpenFreeMap `positron` 样式（OSM 数据，无需 token）
- **双色调**：`MapTint` 在瓦片之上盖一层 4 段蓝色渐变（alpha 0.24–0.42），
  让陆地、水面、标签统一进蓝色系统，同时保留地名可读性
- **标签**：运行时把所有 symbol 图层的 `text-field` 改成
  `coalesce(name:en, name)`，去掉希腊文/阿拉伯文与拉丁文并排的杂音
- **会自己动**：`WorldMap(tour = true)` 每 9 秒在欧/东亚/北美/南美/非洲/南亚之间
  做 3.2 秒的镜头飞行，和原作那种"地图自己在漂"的感觉一致
- **飘卡**：白色 callout 跟随镜头——每次自动巡航落点变化时换一张**你查过的词**
  （词 + 释义摘要）。词池是 `recentAt > 0` 的全部缓存词，后台抓取的每日一词
  `recentAt = 0`，所以除非你点进去看过，它不会出现在地图上。
  回调用 `rememberUpdatedState` 传进常驻协程，否则会一直调用首次组合时的空词表闭包

> 原作 Bowl 地图上的学校名与词数是服务端按赛季下发的内容，页面里不存在、也无法从
> 前端反推。我们只复刻它的**行为**（自动巡航、数字滚动、轮播卡片），数据源换成用户
> 自己的收藏 —— 有意义的动画，而不是伪造的地理数据。

## 地图（早期方案存档）

> 存档：这是改版前的设想，不是当前实现。当前行为见上面的「地图（已实现）」。

参考站首页那张地图是 **Mapbox GL JS**：可拖动、可缩放、国家名 + 城市点、计数器滚动。
安卓端计划：

- **MapLibre Native**（Mapbox GL 的开源分支，Apache-2.0）
- 底图：**OpenFreeMap** 或 Protomaps 的 PMTiles（OSM 数据，无需 token，可商用）
- 样式：自定义 JSON，去掉道路/POI，只留国界、海陆、城市点 —— 这样才像它那种
  「干净的世界地图 + 一点装饰」而不是通用导航图
- 数字滚动：`animateIntAsState` + 自定义 `Text` 逐位动画
- 交互：`MapView` 原生 pan/zoom；镜头动画用 `CameraAnimationsPlugin`

不需要 Mapbox 账号，也没有 token 泄漏风险。


## 动效（2026-11，收敛版）

第一性原理：**一次交互只让一个东西动，且动的东西必须是不透明的。**

前面几版踩的坑都违反了这条：

- 滑入用弹簧、淡出用更快的弹簧 → 旧页先消失，中间露白，看起来像闪屏
- 给淡入加透明度下限"补救" → 两页同时半透明叠在一起，出现**重影**
- 再叠上共享元素和页面内的 AnimatedContent → 一次导航三层动画，掉帧、卡屏

现在的规则：

| 场景 | 动效 | 为什么必要 |
|---|---|---|
| 页面进入/返回 | 无转场，硬切（`EnterTransition.None`） | 全屏滑动在真机上会掉帧，硬切反而更稳 |
| 卡片按压 | `wlPress(scale = 0.985f, dim = false)` | 触摸反馈；整张白卡只缩放不变暗，单层 transform |
| 文字/行按压 | `wlPress()`：缩到 0.96 + 透明度 0.72 | 不用 Material 涟漪——纸面上没有灰色圆角矩形，全局 `NoIndication` |
| 列表增删 | `animateItem` | 交代行的空间关系 |
| 搜索结果 | 逐条上浮（`Surfaced`） | 让结果从水线里长出来，而不是突然出现 |
| 词条内容到达 | 140ms 淡入（`ContentFade`） | 标题与骨架同位置，正文安静浮现，无布局跳动 |
| 练习换题 | 硬切 | 题目之间没有空间关系可交代 |
| 复习换卡 | 水平滑动 1/10 + 淡出 | 交代队列前进 |
| 复习翻牌 | Y 轴旋转 | 翻面本身 |
| 底部抽屉 | Material 默认 | 系统一致 |

**已删除**：导航淡入淡出、共享元素转场、词条页 Loading/Content 的 AnimatedContent、
练习里的过渡。骨架页与内容页标题同位置，内容就绪后只做 140ms 淡入（`ContentFade`），不触发布局重算。

动效令牌只有一个弹簧 `WlMotion.press`（damping 0.7 / stiffness 800）；没有页面转场令牌。

### 词书：开卷与合卷

词书是站内唯一的"表现性"动作，因为它本来就发生在同一张卡上：

- 选书：一张卡沿看不见的圆环滑过屏幕边缘，侧卡向内转（`rotationY -34°`）、略缩，
  不淡出、不升降；过卡一声纸页声（无震动，默认开启）。
- 开卷：点封面或「开始学习」→ 封面绕 Y 轴转 360°（320ms，前段加速），转的同时
  甩出 12 片珊瑚色叶子（560ms，向右、向上偏，越过页面再淡掉）；180ms 后详情页以
  0.48→1 的缩放、`transformOrigin (0.5, 0.45)` 从书的位置展开（360ms）——0.48 时
  纸的宽度正好等于封面，展开起点就是书本身。
- 详情页 **全程不透明**：纸盖在书上，靠缩放交代来处，不做 alpha 淡入——半透明叠半透明
  就是重影。书架也因此不做淡出，保持原色，被纸盖住即可。
- 详情页在进入词书架 220ms 后预先组合在书架 **下面**（`zIndex -1`），打开时只改
  zIndex 和缩放，省掉首次组合的卡顿。
- 合卷：详情页保持不透明地从 1 缩回 0.48，只有最后 40ms 化掉；280ms 时封面开始
  反向转回，约 600ms 结束。缩放和淡出不再同时跑，封面也不会在纸后面空转。
- 系统返回键先合卷，再退出词书架。
- 详情页铺满整个 Box 并吞掉指针事件，避免点击穿透到还在挂载的书架。
- 列表按每 100 词分段，段头是 `第 n 单元` 与右侧 `x / y 词` 的两端对齐文字；行可点击，直接进词条。
- 详情页**不用分隔线**：整本进度是一个百分比加一行字数，单元之间靠 30dp 留白分开，
  唯一的线是当前筛选项下面那 18dp 短横。之前的进度条、表头通栏细线、单元引导线叠在
  一起，像三张表格压在同一屏上。


### 学习卡状态机（2026-11）

一张卡只有三种状态，且**评分不可撤销地锁定**：

| 状态 | 手势 | 出口 |
|---|---|---|
| 未评（Word） | 滑动无效 | 点四档之一 → 锁定评分，进入环 |
| 已评（环） | 主卡与例句是同一横向环：页面跟手，**左滑前进**（下一页从右侧进入）、右滑后退，首尾相接（末条左滑回主卡，主卡右滑进末条） | 下一词 / 记错了；「中文」切中文层 |
| 中文层 | 下滑回英文环 | 「英文」切回、下一词 / 记错了 |

- 从评分面进入已评后，**没有任何路径回到评分面**——点评分面本身也不再响应点击。
- 层间切换不再用淡入淡出：一律整幅位移，方向跟手势一致；例句页跟手移动，
  相邻例句从对应一侧滑入。**翻页不震动**（震动只留给评分与揭晓）。
- 翻页在**松手那一刻**生效，而不是等回弹动画结束：连续快滑不会把上一次翻页取消掉；
  位移超过卡宽 12%，或速度达到 **400dp/s**（约 2.5 英寸/秒）就翻页——短促轻扫也生效，
  不必拖长距离。阈值按 dp 计算，所以不同屏幕密度上手感一致。
- **主卡只放词条本体**（中文释义 / 导读 / 义项 / 同族）；第一条例句只出现在环的第 1 页，
  避免主卡与首屏出现同一句话。
- 环的左右邻居都提前组合在画布外，拖动第一帧不需要再排版新页面；位移只写
  graphicsLayer（绘制层），不触发逐帧重组。发音按钮的呼吸动画**只在播放时存在**，
  否则一屏三个喇叭会让 UI 线程每帧都在跑。
- 本场已评的词可以从头部「回顾」只读打开（显示当时选了什么），「更早」往回翻，
  「回到当前」回到还没提交的卡；回顾层吞掉触摸，不会误改当前卡。

### 声音与庆祝（2026-11）

四档评分在**点下评分的那一下**出声（不是提交时），都是合成出来的短音（`tools/sfx/make_sfx.py`），
不用第三方素材、不用蜂鸣器：

| 评分 | 声音 | 为什么 |
|---|---|---|
| 秒懂 | 明亮上行五度（A5→E6，玻璃铃） | 答对，清亮、有完成感 |
| 认识 | 同音色大三度（C5→E5），更短更轻 | 对了，但不庆祝 |
| 模糊 | 单个中音，不上行 | 有印象、没到位，不夸奖也不责备 |
| 忘记 | 干燥的短"嗒"，音高不变 | 中性结束，不打击 |

学习卡上的进度环与顶部底色从应用蓝改为墨色（环 0.78 不透明、笔头小圆点），
朗读中的喇叭也从蓝色底换成淡墨底——背单词页里不再出现品牌蓝。

拼对是三滴上行的琶音，拼错是一声干燥的木音。拼对时在卡片上盖一枚墨色印章：
弹簧压入（有重量）、勾自己描出来、六粒墨点随落笔散开，约 450ms 后进入下一词。
没有彩纸和星星——奖励属于一本书。

### 声音页（2026-11）

- 纸面色：浅色 `#F7F4ED`，卡片 `#FFFDF8`，发丝线 `#E3DDCF`，选中底 `#EFE9DB`；
  深色分别用 `surface` / `surfaceAlt` / `outline`。这是唯一使用暖纸底的设置页。
- 字号：标题 14.5sp、正文 11.5–12sp、分区标签 9.5sp、音色注释 8.5sp；
  **整页不超过 14.5sp**，不跟随其它页面的字号。
- 音色卡：64dp 高、7dp 间距、7dp 圆角、1px 自绘波形（每个音色不同疏密，两端渐隐）；
  选中 = 纸白填充 + 1px 墨边 + 抬 2dp + 很轻的投影，未选中只留发丝轮廓。
- 分区字形：13dp 单线（波形 / 播放 / 钥匙 / 喇叭 / 重置），在 Compose 里用 Canvas 绘制，
  不是 `res/mipmap` 图标；因此不参与下面 24 个 drawable 的网格。
- 结构：朗读（模板分段 + 音色卡 / 描述）→ 试听（文本 + 六个快选词）→ 连接（默认折叠）
  → 音效（两列开关 + 音量 + 分组试听）；底部固定试听 / 保存，常规高度不滚动。
- 全部开关与滑杆即时生效（音效），TTS 只在保存时落盘；错误显示在底部按钮上方，不藏在滚动区。
- 连接展开里是两枚下划线文字「MiMo / OpenAI 兼容」；OpenAI 时朗读区换成说明、
  连接里出现模型与声音字段，MiMo 模板/音色卡隐藏。

## 图标（2026-11）

全站不再使用 Material 默认图标。一套 24 个自绘矢量（不含启动图标），统一 24 格网格：
**浅色填充 + 1.2–1.5 描边 + 一颗珊瑚色线结**。线结是全套的签名——每个图标在
"线头收尾"的地方留一个小圆点，像织布时打的结。

| 喇叭 | `wl_volume` | 发音、全部连读 |
| 卡片夹 | `wl_list` / `wl_list_knockout` | Add to list、品牌行 |
| 图钉 | `wl_pin` / `wl_pin_knockout` | 学习地图入口（当前用 `_knockout`） |
| 线箭头 | `wl_forward` | 卡片里的前进箭头 |
| 弯箭头 | `wl_chevron` | 列表行尾部 |
| 交叉线 | `wl_close` | 从词表移除 |
| 摊开的书 | `wl_book` / `wl_book_knockout` / `wl_book_light` | 「查一个词」卡（三种底色各一版） |
| 四角星 | `wl_spark` / `wl_spark_knockout` | 「随机一个词」、练习结果 |
| 归档箱 | `wl_archive` / `wl_archive_knockout` | 备份导出 |
| 回复箭头 | `wl_restore` | 备份导入 |
| 加号 | `wl_plus` | 新建词表 |

颜色不走 tint，而是走资源限定符：`values/icon_colors.xml` 与 `values-night/icon_colors.xml`
各一套 `wl_icon_ink / fill / fill2 / accent`，矢量里直接引用，夜间模式自动换色，Compose 侧
用 `Icon(painter, tint = Color.Unspecified)` 保留双色。

三种上下文各有一套变体，别混用：

- **主题色**（默认）：随浅色/深色切换，用在页面底色上
- **`*_knockout`**：白色蚀刻版，用在饱和蓝底上（首页品牌行、地图）
- **`*_light`**：永远用浅色墨，用在"无论深色模式都是白底"的面上（首页搜索胶囊、白卡片里的书）

返回键选了斜置的长剑而不是箭头：横向的剑在 24dp 下只剩一根细线，斜置才能把剑身、护手、
剑柄和珊瑚色配重都放进去，也才看得出是"剑"。

## 搜索页与词表页（2026-11 重做）

这两页原先都是「白底 + 灰字 + 细分割线」，和首页放在一起像另一个 App。问题不在布局密度，
而在**没有场**：首页有一整块藏蓝渐变、波浪边缘、被蓝场托起来的卡片，这两页什么都没有。

重做只引入一件东西：把首页 hero 的「浅水区」搬过来。

```
┌ 藏蓝渐变（#061B45 → #0C3B9E）──────────┐
│ ← 返回                    [ + ]        │
│ 词表                                   │  ← 30sp 衬线白字
│ 2 个词表 · 0 个词                       │  ← 12sp 白 72%
│      ～～～ 波浪（surface 色）～～～     │  ← 与首页同一条正弦
├────────────────────────────────────────┤
│  Reading   ← 首字母衬线块 46dp + 衬线 17sp
│  GRE
└────────────────────────────────────────┘
```

- 渐变与波浪直接复用首页的 `WaveDivider`，两页共用 `PoolHeader`
- 标题用衬线白字而不是 AppBar 小字，页面因此有"封面"而不是"工具栏"
- 内容区回到纸面：`surface` 底色，无边框无阴影，靠**排版层级**而不是卡片堆叠
- 搜索页在空白态给两段可读内容：**最近查过**（衬线胶囊）和**随机一个词**（卡片）；
  有输入时按「匹配的词 / 短语」分组，词用衬线藏蓝 20sp，释义 13sp 灰
- 词表卡片左侧是首字母色块，色调按序轮换（蓝 / 珊瑚 / 薄荷 / 绿），
  和首页那排功能卡共用一个色板
- 两页都没有搜索框以外的阴影：高级感来自色场和字，而不是投影

深色下渐变收成 `#04101F → #0B2A5B`，波浪几乎贴住底色，只留一道很弱的边。

词表详情与复习页也用同一个 `PoolHeader`：详情页的标题就是词表名（衬线白字），
行里显示缓存到的释义；复习页把「已复习 / 待复习」放在蓝场右侧，卡片回到纸面。

所有选择器都走底部抽屉（`WlSheet`）：纸面色、28dp 圆角肩、4dp 拖拽条。
「加入词表」把词名用衬线斜体放在标题下，列表行带首字母色块；新建词表是同一个抽屉里的
一行输入（无边框、浅底、圆形「创建」按钮）。全站不再出现 Material 的矩形 `AlertDialog`。

### 备份

首页品牌行第三个图标进入「备份与恢复」抽屉：导出写成 JSON（系统文件选择器，无存储权限），
导入是**合并**而不是覆盖——卡片与词条按主键 upsert，词表按「名字 + 创建时间」匹配，
重复导入同一份文件不会产生重复词表。导出用 `openOutputStream(uri, "wt")`：某些 provider
对普通 `"w"` 会留下 0 字节文件。

### 长按选词与翻译

词条页的导读、释义、例句都换成了 `SelectableText`：长按落在哪个词就选中哪个词（系统
`LONG_PRESS` 触感），横向拖动按词扩展（每跨过一个词给一次 `CLOCK_TICK`），松手后在选区
旁边浮出一张玻璃卡，自动避开屏幕边缘。

没有用 Compose 的 `SelectionContainer`：它不给选中文本，也不给自定义动作，系统工具条里
塞不进「翻译」。自己算词边界（字母/数字/连字符/撇号算词内），代价是选择粒度是词而不是字符
——对"选词和短语翻译"正好。

翻译先用 **有道**：单词走 `dict.youdao.com` 词典接口（返回原生词性行，词性单独成列），
短语和句子走 `aidemo.youdao.com`；无网络或接口异常时回退 **ML Kit 端上模型**（en→zh，
首次下载约 30MB，之后离线）。`TranslationService.translate` 是唯一入口，
换 DeepL / 云翻译只改这一层。

卡片是 Haze 磨砂玻璃：`hazeSource` 在词页、`hazeEffect` 在卡片，先 `clip(shape)` 再取景，
所以圆角只有一层、不会露出直角；底部只有「EN 复制原文 / 译 复制译文」两个动作，点卡片外
关闭。

### 练习（Quiz）

四选一释义题，题目全部来自本地缓存（最多 300 条），**不新增任何网络请求**。
干扰项取其他词的第一条义项，答对/答错只影响这一轮，**不写 FSRS 队列**——排期仍由复习页决定。

- 题干用衬线藏蓝 36sp 放在浅底卡上，选项 15sp 圆角 16dp
- 选中后：正确项转绿（描边 + 12% 底），错选项转珊瑚，其余降透明度
- 结果页给「再练这 N 个 / 再来一轮 / 返回」，错词以衬线胶囊列出
- 缓存不足 4 个词时不出题，直接说明原因

## 词条页（2026-11，按原站 CSS 复刻）

词条页的值**不是**采样出来的，而是从参考站的 `dictionary-*.css` 里直接读到的 CSS 变量与选择器。
这是踩过坑之后的规则：**颜色一律以样式表为准**——截图里同一处文字边缘会因为抗锯齿混出
`#14243A`、`#2D4D80` 之类的假色，和真值能差出 20 多个亮度级。

| `WordLook` 字段（`ui/word/WordScreen.kt`） | 值 | 对应原站 |
|---|---|---|
| `headline` | `#00578A` | `.word-area h1` / `.span-replace-h3`（标题、音标） |
| `link` | `#0090E3` | 描边按钮、链接 |
| `lead` | `#222222` | `.blurb.short` 短导读 |
| `body` | `#444444` | `.blurb.long` 长导读 |
| `forms` | `#545454` | `p.word-forms` |
| `example` | `#666666` | 例句 |
| `panel` | `#EDF7FC` | 浅蓝底块 |
| `banner` | `#BE6DCF` | `Definitions of …` 紫色横幅 |

词性色沿用原站 `--pos-color-*`：

| 词性 | 色值 |
|---|---|
| noun | `#0FA646` |
| verb | `#CD4D03` |
| adjective | `#007BC4` |
| adverb | `#7B61FF` |
| preposition | `#BE6DCF` |
| pronoun / conjunction | `#44AA02` |
| interjection | `#FA52B7` |

结构（自上而下）：

```
← 标题行（返回 · 书签 · 刷新）        ← 不再重复词名，标题就在下面一行
quick  [☰ Add to list]            ← 36sp 衬线藏蓝 + 描边按钮
🇺🇸 🔊🔊 /kwɪk/  [🔊 全部]          ← 旗帜 + 每条录音一个喇叭 + 音标 + 全部连读
Other forms: quicker; quickest; quicks   ← #545454，词形加粗
如果……                             ← 短导读（衬线 17/28）
这段词还有一层意思……                 ← 长导读（无衬线 15/25 #444）
▛ Definitions of quick ▟          ← 紫色斜角横幅，白字斜体词名
1. (adjective) moving quickly…    ← 编号 24dp + 词性胶囊 + 正文
   "quick of foot"                 ← 斜体例句
   synonyms: agile, nimble, spry   ← 藏蓝，整行可点进同义词页
   显示全部 8 个义项 · 全部同义词     ← 两个文字按钮
Word family                        ← <vcom:wordfamily>，胶囊可点
复习进度 [====----] 0/8            ← 只在已收藏时出现，FSRS 本地状态
```

- **义项行**：序号 24dp + 词性胶囊（10% 同色底 + 1dp 40% 同色描边）+ 正文
- **收藏态**：已在复习队列用亮蓝填充书签（`#005AFB` + 白结），不在队列用主题双色书签（`wl_icon_fill` + 珊瑚结）
- **书签的两个动作**：点按 = 加入 / 移出复习队列；**长按 = 只加入 / 移出收藏夹**（不动 FSRS 排期，Toast 确认）。
  背单词自动加入队列的词因此也能进收藏夹，而不需要先丢掉复习进度
- 正文默认只显示 4 条义项，与参考站折叠行为一致
- **不再有底部双按钮**：加词表走标题旁的 `Add to list`，加复习走右上书签，
  底部重复一次只是把同一动作说两遍，还占掉半屏
- **顶部不再写一遍词名**：AppBar 左边只留返回箭头，词名交给 36sp 标题

### 同义词页

`SynonymsScreen` 把各义项的 synonyms 按义项分组，每条形如「义项序号 + 词性 + 定义（衬线斜体）
+ 胶囊词」；点任意胶囊进入该词的词条页。数据全部来自已经在内存里的 `WordEntry`，
进入这个页面不会再发一次网络请求。

### 深色模式

原站只有浅色一套，所以深色不是抄来的，而是把这套身份**抬亮**后重建的：色相不变，亮度提高，
保证在 `#0B1320` 上仍然读得清。实现是 `WordScreen.kt` 里的两个 `WordLook`（`LightLook` /
`DarkLook`），按 `wl.isDark` 二选一，不给中间态留混用的机会。

| 用途 | 浅色（原站） | 深色（本项目） |
|---|---|---|
| 标题 / 音标 | `#00578A` | `#6FC3EA` |
| 链接、描边按钮 | `#0090E3` | `#4CB8F5` |
| 短导读 | `#222222` | `#E6EBF1` |
| 长导读 | `#444444` | `#BFCAD8` |
| Other forms | `#545454` | `#9AA9BE` |
| 例句 | `#666666` | `#93A2B5` |
| synonyms 标签 | `#888888` | `#7D8CA0` |
| 浅蓝底块 | `#EDF7FC` | `#16293A` |
| 紫色横幅 | `#BE6DCF` | `#BE6DCF`（保持不变，白字仍可读） |

词性色同样各给一套亮色版本（noun `#4BD58A`、verb `#FF9350`、adjective `#56B6F0`、
adverb `#A894FF`…），由 `posColor(pos, dark)` 选择。

复习进度条在深色下用主题 `primary`（亮蓝）画进度、`panel` 画轨道；`#00578A` 在深底上
会糊成一片，不再使用。
