# 第三轮：词书范围

> 只谈「收哪些词、按什么顺序、怎么分组、从哪来、怎么验证」。
> 卡与动效、会话交互不在本文。

---

## 1. 判定标准

一本词书值不值得做，只看四条：

1. **覆盖率**：学完之后，真实文本里还有多少词不认识；
2. **可学性**：词的难度是否连续，会不会一页里全是生僻词；
3. **可维护**：词表来源是否稳定、授权是否清楚、能否脚本重建；
4. **可获得性**：每个词能否拿到释义、音标、发音、例句（我们的词条链路）。

这四条决定了「核心词书优先、考试词书其次、专业词书不做」。

---

## 2. 三个维度

### 2.1 收词：按词族，不按词形

`great / greater / greatly / greatness` 是一个学习单位。词书存**词族代表词**
（lemma），学习时展开家族。依据：Nation 的覆盖率研究以 word family 为单位，
3000 个词族即可覆盖日常口语的绝大部分。

### 2.2 排序：词频降序

- 初学者最优解是「先学最常用的」，覆盖率增长最快；
- 考试词书的内部顺序也按词频，而不是字母——字母序只适合当查找表；
- 提供「按字母」切换，但默认关闭。

### 2.3 分组：单元制

每 100 个词族一个单元。理由：

- 进度可感知（12/30 单元），而不是「还剩 2147 个」；
- 会话有明确终点，适合碎片时间；
- 与拼写模式天然对齐（每单元末抽拼写）。

## 4. 首发范围（按本轮决定修订）

### P0：两本考试核心 + 三本自动书

| 词书 | 词族数 | 单元 | 来源 |
|---|---|---|---|
| **通用核心 3000** | 2,809 | 29 | NGSL 1.2 |
| **四六级核心** | 2,500 | 25 | CET-4/6 大纲词 ∩ 词频前 2,500 |
| **考研核心** | 3,000 | 30 | 考研大纲词 ∩ 词频前 3,000 |
| 查过的词 | 动态 | 自动 | 本地缓存 |
| 错词本 | 动态 | 自动 | `study_log` 中 Again ≥ 2 |
| 收藏夹 | 动态 | 自动 | 现有 deck |

只删了**学术核心（NAWL）**：词太深，日常阅读和考试都用不上。通用核心保留在 P0，
它是打底的一本，和两本考试书并存。

**高频词不预设跳过**：the / of / and 这一层照常收进词书。学习时用「秒懂」快速推进，
不替用户判断「你会不会」；后续可选手动「标记熟知」，但不做全局预设。

**规模已定**：四六级核心 2,500 词族、考研核心 3,000 词族，按 100 族/单元切分
（25 / 30 个单元）。裁掉的是大纲里的低频长尾。

三本书会大量重叠（NGSL 与大纲的交集）。处理方式：**记忆状态挂在词上**，同一个词
只学一次；在另一本书里它显示为「已学」，**自动跳过**，不占用新词额度、不打断复习节奏。
进度按书独立统计：已学的词计入那本书的完成度，但不算作当天新学的词。

### P1

| 词书 | 规模 | 说明 |
|---|---|---|
| 雅思核心 / 托福核心 | 3,000 | 公开词表 + 词频裁剪 + 抽样校对 |

### P2

- 四六级 / 考研**完整大纲版**（4,500 / 5,500），给需要全覆盖的人；
- 核心 5000（词频扩展）。

### 明确不做

- 学术词书、专业词书（医学/法律/计算机）；
- 教材同步词书（版本多、更新快）；
- 内容型词书（每日一词合集、名人演讲词）——和记忆系统无关。

## 5. 词书数据从哪来：能不能直接从「不背单词 / 墨墨」拿？

**技术上能，但不该作为主路径。**

### 5.1 直接提取要付出什么

- **不背单词**（`cn.com.langeasy.LangEasyLexis`）：词书按需下载，落在应用私有目录；
  APK 内的资源多为打包/加密格式。要拿就得拆包（jadx 找资源解密与接口）、抓包
  （mitmproxy，通常还要处理证书固定）、在 root 设备上导出数据库。
- **墨墨背单词**（`com.maimemo.android.momo`）：词书走账号体系与接口，需要登录态和
  签名参数，接口随版本变动。
- 两者都有完整性校验；今天导出的表，下次更新就可能对不上。

更关键的一点：**它们的词书本来就是考试大纲**。绕一圈逆向拿到的，还是同一份公共词表；
它们真正的增值（原声例句、助记、考点标注）不在这份表里，而那部分更不该搬运。

结论：把逆向成本花在「词表」上性价比极低，而且不可维护。词表用公开大纲，
逆向最多用来做交叉校验。

### 5.2 主路径：公开大纲 + 双源校对 + 词频裁剪

1. **收集**：四六级、考研大纲词表以公开出版物 / 教育机构公布的版本为准；
2. **双源比对**：从两个独立的公开仓库各取一份电子版做 diff——
   - 两边都有 → 收录；
   - 只有一边有 → 用词典存在性 + 词频判断，人工抽查；
   - 拼写差异 → 以词典 headword 为准；
3. **裁剪与排序**：用 COCA / SUBTLEX 词频，四六级取前 2,500、考研取前 3,000；
4. **可用性抽检**：随机 100 词跑词条链路，确认释义 / 音标 / 例句可得；
5. **固化**：脚本 + 来源 URL + 抓取日期 + 文件哈希一起入库，词表更新可重跑、可追溯。

### 5.3 两款 App 只用在校验

各抽 20 个词，对照它们的书里有没有、排序是否接近；不搬运例句、助记、音频。
如果发现我们缺了常用词，回到 5.2 补进大纲表，而不是从 App 里抠。

## 6. 数据管线

### 6.1 输入

- `ngsl.csv`：headword, rank, band
- `nawl.csv`：headword, rank
- `cet4.txt`、`cet6.txt`、`kaoyan.txt`：大纲词，一行一词
- （P1）`coca_rank.csv`：lemma → rank，用于裁剪与排序

### 6.2 处理步骤

```
原始词表
  → 规范化：小写、去空格、统一连字符、英美拼写合并（colour/color）
  → 过滤：专有名词、缩写、单字母、纯数字
  → 词族归并：lemma → family head（离线词形还原，见 6.3）
  → 去重：同一家族只保留词频最高的代表词
  → 裁剪：考试书按 COCA rank 取前 N
  → 排序：核心书用 NGSL rank；考试书用 COCA rank
  → 切分：每 100 族一个单元
  → 输出
```

### 6.3 词族归并怎么做

不在运行时调 vocabulary.com 的 `wordFamily`（要联网、慢、4000 次请求不现实）。
在桌面端一次性生成：

1. 用 WordNet + 简单屈折规则（-s/-es/-ed/-ing/-er/-est/-ly）把词形映射到 lemma；
2. 人工抽查 200 个高频词的家族，修正明显错误（如 `better → good`）；
3. 产出 `family_map.json`：`lemma → [members]`，只覆盖词书内的词，预计 < 300KB；
4. 运行时若词条里带 `wordFamily`，以词条为准合并两边的并集。

### 6.4 输出格式

```
assets/books/core3000.txt      # 一行一个代表词，按词频
assets/books/nawl.txt
assets/books/cet4_core.txt     # P1
assets/books/index.json        # 书名、类型、单元数、来源、授权、构建时间
```

单个词表约 2,800 行、25KB；对 121MB 的包体无影响。

## 7. 校验：怎么证明这本词书值得背

### 7.1 覆盖率实测

- **语料**：用我们已缓存的词条导读/长释义（几千段真实英文），加上一小份公开新闻
  样本（各 10 万词量级）；
- **指标**：`覆盖率 = 语料中被词书（含更早单元）覆盖的 token 比例`；
- **输出**：每本词书、每个单元的边际覆盖率曲线——前 500 词应该陡升，之后趋缓；
  如果某单元几乎不涨覆盖，说明排序有问题。

### 7.2 词条可获取性

随机抽 100 个词跑词条链路（vocabulary.com → Wiktionary 回退），统计：

- 有释义的比例（目标 ≥ 98%）；
- 有音标/发音的比例（目标 ≥ 90%）；
- 有例句的比例（目标 ≥ 80%）。

缺的记入 `book_gaps.txt`，下一版替换或补录。

### 7.3 难度连续性

用词频分档检查每个单元内部的 rank 方差——同一单元里不该混入相差 5000 名的词。

## 8. 词书在界面里的信息

牌面只放四个信息，多一个都不放：

```
┌──────────────────────┐
│  核心 3000            │   ← 书名，衬线
│  2,809 个词族          │   ← 规模
│  ▓▓▓▓░░░░░░  12/29    │   ← 单元进度（细线，非粗条）
│  通用 · NGSL          │   ← 一行来源标签
└──────────────────────┘
```

- 进度按「单元」而不是「词」计算，学习时按单元推进；
- 自动书（查过的词 / 错词本 / 收藏夹）不上进度环，只显示词数与「继续」；
- 词书详情页是单元列表（29 行），点单元进入该单元的学习，而不是整本书从头开始。
